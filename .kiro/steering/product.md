# Product Overview

Azure DevOps Story Reviewer is a cross-browser extension that integrates AI-powered feedback directly into Azure DevOps work item pages. The extension extracts user story content and provides intelligent suggestions to improve story quality and completeness.

## Core Features

- **Smart Content Extraction**: Automatically extracts titles, descriptions, and acceptance criteria from Azure DevOps work items
- **AI-Powered Feedback**: Supports OpenAI, Anthropic Claude, and Mistral APIs for generating feedback
- **Seamless Integration**: Adds "Get Feedback" button directly in Azure DevOps UI
- **Customizable Prompts**: Users can define custom prompt templates with variable substitution
- **Copyable Snippets**: Generated feedback includes copyable text snippets for direct pasting into Azure DevOps
- **Cross-Browser Support**: Works with Firefox and Chrome-based browsers

## Target Users

- Product Managers and Product Owners
- Software Engineers and QA Engineers
- Scrum Masters and team leads
- Anyone working with Azure DevOps work items

## Key Value Proposition

Improves user story quality by providing instant, AI-powered feedback on clarity, completeness, testability, and adherence to best practices, directly within the Azure DevOps workflow.
